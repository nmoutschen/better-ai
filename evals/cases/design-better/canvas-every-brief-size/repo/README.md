# Harbour Desk

Support tool for the Harbour invoicing product. Agents handle tickets from email, chat and phone; most of the field team
works from their phones between customer visits.

Run it locally with `python3 -m http.server 8000` and open http://localhost:8000/ticket.html.

- `ticket.html`: one ticket, its header and the conversation.
- `DESIGN.md` and `tokens.css`: the design language.
- `.design/`: briefs and versions for design work in progress.
