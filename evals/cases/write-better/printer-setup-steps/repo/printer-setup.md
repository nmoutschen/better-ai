# Printer setup

When you start, you will need to set up the third-floor colour printer on your laptop yourself, which is easy once you
know where everything is, so first make sure you are connected to the office Wi-Fi network called HARBOUR-STAFF (not
HARBOUR-GUEST, because the guest network cannot see the print server) and then open Settings, go to Bluetooth & devices
and then Printers & scanners, and click Add device, then wait a few seconds until the link "The printer that I want isn't
listed" appears and click it, then choose "Select a shared printer by name" and type `\\PRNSRV-02\Floor3-Colour` exactly
as written, and when Windows says it cannot find a driver, click Have Disk and browse to
`\\fs01\drivers\ricoh\IMC3000\x64`, select the file IMC3000.inf and click OK, after which the installation takes a
minute or two, and once it has finished you should open the printer's Printing preferences and set Colour mode to Black
and White so that you don't print in colour by accident, since colour pages are charged to your team's budget, and
finally print a test page from the same window to check that it works, and if anything goes wrong at any point, call the
IT desk on extension 4410 and ask for Sione, who looks after the printers.
