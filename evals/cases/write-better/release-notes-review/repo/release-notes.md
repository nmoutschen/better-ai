# Fernpad 4.2 release notes

Thank you for using Fernpad. This release brings a number of improvements across the app, many of them based on your feedback over the last quarter.

## Improvements

Photo uploads are faster. On a typical mobile connection, a batch of 20 site photos now uploads in about half the time it took in 4.1, and uploads resume where they stopped if the connection drops.

Search now finds notes by the name of the person who wrote them, as well as by their text.

We also resolved PLAT-2291, which several of you reported in October.

## Other changes

The settings page has been reorganised so that notification options sit together under one heading. As part of this release, the CSV export in the old format will stop working on 1 February 2027, so any spreadsheet or script that imports Fernpad exports needs to switch to the new format before then; the new format is described in the help centre under "Exporting your data". Exports created before that date are not affected.

## Coming next

Dark mode is coming soon, along with offline editing for checklists.

If you have questions about this release, contact support@fernpad.example.
