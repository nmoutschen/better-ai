# Take-away

A take-away is a Markdown file the user keeps after the lesson: `.teach/<topic-slug>/take-away.md`. Section 6.2 of SKILL.md says when to write it and what goes in it. Copy the block below and replace the `<placeholders>`. Leave out a section that has nothing to hold, such as "Mistakes to watch" when the user made none.

Put the review questions first, with the review dates planned in section 4.2 of SKILL.md. Keep their answers in a separate section at the end, so the user answers before they look.

```markdown
# <topic>: take-away

You can now: <the GOAL, as a task the user did in the quizzes>.
Still to practise: <what the quizzes showed the user struggled with, or "nothing the quizzes showed">.

## 1. Review questions

Review on <date 1>, <date 2> and <date 3>. Each time:

1. Answer every question from memory, before you look at the rest of this file.
2. Check your answers in section 4.
3. For each question you missed, reread its part of section 2, then answer it again at the end of the session, until you get it right once.

Questions:

1. <question on a rule or fact the GOAL needs>
2. <question that applies a rule to a case the lesson did not show>
3. <question on a mistake the user made in practice or a quiz>

## 2. Reference

### <chunk title>

<rule, with the conditions under which it holds>

| Symbol | In the example |
|---|---|
| <symbol> | <what it stands for in the example> |

Example: <the worked example from the chunk, each step with its reason>

Source: [<source title>](<url>)

### <next chunk title>

<...>

## 3. Mistakes to watch

- <mistake the user made> → <the rule it misapplies, and where section 2 covers it>
- In your own summary: <what it left out or got wrong> → <section of this file that covers it>

## 4. Answers

1. <answer, with the reasoning>
2. <answer, with the reasoning>
3. <answer, with the reasoning>

## Not covered

- <chunk not taught, or "Every planned chunk was taught.">
```

In the chat, SEND the same content as one message, with the same headings.

On a page, ADD a last chunk with one `text` card per section above. Put the answers on the last card.
