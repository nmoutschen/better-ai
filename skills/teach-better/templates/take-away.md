# Take-away

A take-away is a Markdown file the user keeps open while they use the topic: `.teach/<topic-slug>/take-away.md`. Section 6.2 of SKILL.md says when to write it and what goes in it. Copy the block below and replace the `<placeholders>`. Leave out a section that has nothing to hold, such as "Mistakes to watch" when the user made none.

Keep the worked solutions to the practice tasks in a separate section at the end, so the user attempts each task before they look.

```markdown
# <topic>: take-away

You can now: <the GOAL, as a task the user did in the quizzes>.
Still to practise: <what the quizzes showed the user struggled with, or "nothing the quizzes showed">.

## 1. When to use this

| When you see | Use |
|---|---|
| <a sign in the user's situation that a rule applies> | <rule or step, and where section 2 covers it> |

Your plans:

- When <situation>, I will <step from the lesson>.

## 2. How to do it

### <chunk title>

Steps:

1. <step>
2. <step>

Rule: <rule, with the conditions under which it holds>
Why it works: <one or two sentences, so the user can adapt the steps to a case the lesson did not show>

| Symbol | In the example |
|---|---|
| <symbol> | <what it stands for in the example> |

Example: <the worked example from the chunk, each step with its reason>

Source: [<source title>](<url>)

### <next chunk title>

<...>

## 3. Mistakes to watch

- <mistake the user made> → <the rule it misapplies, and where section 2 covers it>

## 4. Practice

Practise on <date 1>, <date 2> and <date 3>, or as soon as you next use this. Each time:

1. Do each task without looking at this file.
2. Check your work against section 5, then reread the part of section 2 that covers anything you missed.
3. Do a new task like each one you missed, from your own work if you can.

Tasks:

1. <task from a situation where the user will use the topic>
2. <task in a different situation, that applies a rule to a case the lesson did not show>
3. <task built on a mistake the user made in practice or a quiz>

## 5. Worked solutions

1. <solution, each step with its reason>
2. <solution, each step with its reason>
3. <solution, each step with its reason>

## Not covered

- <chunk not taught, or "Every planned chunk was taught.">
```

In the chat, SEND it as one message with the same headings. On a page, PUT the worked solutions on the last card.
